# 跨章节贡献与证据定位

复用既有大纲或核查说明中的一处定位记录，各写作阶段读取或链接同一记录。新项目在现有大纲阶段形成，完整手稿修订可在入口回填；不新增阶段、强制YAML字段或复制多份表格。已有作者决定直接沿用。

记录研究问题与贡献类型、关键发现及证据位置、决定性反证与必要范围、读者能判断什么、最近邻文献支持状态及章节位置。实现能力、实证认识、文献新颖性与临床作用分别判断；组合方法或阴性结果本身不自动证明新颖性。文本核对不叫科学验证通过。

Introduction对齐问题、设计区别和可评估能力，沿用其不报本研究结果的默认政策；Results给有范围的发现，Discussion说明回答了什么，Abstract/Highlights选择主要支持与会改变主结论的反证。同一事实和证据强度相容，各章不必逐字复述。短文本可省次要分析，内部记录取舍；不规定贡献或限制的条数。

限定是否必要取决于其支配的具体论断。每项删并说明：原来限制什么、候选哪处继续承担同一范围、分析切换时哪里失效。研究设计/分析/估计三类仅帮助盘点，不能规定只在某章或只说一次；摘要、亮点、图注可各需自己的范围。不按not/no/without/descriptive/unresolved等词性批量删除，也不把已有CI视为自动足够的推断说明。

复核问题—证据—贡献是否清楚；相近点估计是否被误写成等效/无代价；阴性或异质性是否被改成未检验机制/临床效用；摘要省略的反证是否改变结论。清楚自然的原文可保留。词频、篇幅和引用密度只作诊断，无通用配额。

部署与稿件分开验收：规则/代码版本、实际加载路径及依赖SHA、片段改善、三语同步、正式源稿接入、Word视觉/引文字段、作者认可分别登记。安装哈希差异先审读来源与内容，不直接当损坏覆盖；历史版本未知时不倒推写作原因。

## 共同写作与核验边界

围绕研究问题、主要发现及其意义组织正文，先写读者需要知道的结果；关键发现、限制、段落、句数和文献量不设通用条数。按证据角色连接已知问题、方法选择、直接比较、解释和反证，同一关键来源可支持不同论断，不按“一段一篇”或每段固定文献数组织文字。数字、标点、词频、句长和引用密度是审读线索；除明确作者或期刊限制外，不为清零提示凑数、加长、拆句或机械合句。

范围声明可以支配明确界定的同小节/同节后文：记录对象、队列、终点、数据划分、种子/子集、方法和推断状态及开始/结束位置，逐项映射后继论断。在同一标题（如 Results 的每个 `###` 子节或无子节的 `##` 节，以及整个 `Discussion`）下，单次运行/单种子等范围声明保留在首次进入该单次运行分析的一处，后文只要仍在同一次运行内，**即使更换了评估指标、中间特征探针、主/次要终点、队列或病例，也直接由新指标或队列名表明测定内容，必须去掉重复的单次运行起句**，不以“分析对象变化”为由逐段复述。前一段已用明确运行编号（如 `in seed 0`）声明单次运行时，同小节后段直接继承并删去 `in the same single evaluated seed` 等重复短语；同一自然段内不重复出现两次单次运行短语。只有中间插入了多次运行汇总并再次切回单次运行时才就近重标一次；`Discussion` 除开篇总结段、专门讨论单次运行设计局限的句子及同句直接对比单次与多次运行稳定性的句子外，其余段落一律继承并删去重复的 `in the single evaluated seed`。跨文件继承需要显式证据对应，不能只凭同标题推断。摘要、Highlights、图注和表注等可被单独阅读的单位各自保留理解其主张所需的一次范围，不把正文声明当成这些单位已经写过。对 `Results` 与 `Discussion`（含文献段、局限段和结论段）中超过 30–35 词的过载复合句，按逻辑拆成两到三个直接清楚的句子，保留段内全部数值、区间、引用与限定集合。当一句比较某一终点而句末用 `, alongside ...` 挂上另一无关领域的测定时，**严禁把 `alongside` 机械替换成 `with`（造成 `, with ..., with ...` 或跨终点硬接）**，应将该独立测定拆成独立分句/短句或并入介绍总体表现的句子；原段无额外界值时允许使用 `was preserved` 等完整状态谓语成句。严禁把句首 `Alongside [X], these results...` 机械改成语义含糊的 `With [X], these results...`（应写清 `Combined with [X], ...` 或 `Together with [X], ...`）；严禁把“点估计达标但置信区间下限低于目标”的真实让步从句 `although / though` 机械改成 `with ... -ing`（若后半句另有 `, whereas` 对比其他队列，应保留 `although / though` 并在分号或句号后另起分句）。不要把 `whereas` 当作句间默认连接词，但也不将其作为清零禁词：在真正构成同句二元反差处（如单次运行的正向差值对比其余运行区间跨零）自然保留 `whereas`，将非直接对立的并列结果或“前人研究 vs 本研究”改用句号拆句或直接动词衔接。在 `Introduction` 与 `Discussion` 连续介绍三篇及以上相关文献时，先写一句归纳性判断或比较角色引导句，再分两到三句陈述各研究及其 PMID，既不无引导地逐篇平铺，也不塞进一个超长分号句；几篇文献可以收在同一句，仅当每篇都支持这同一个谓语。当某一比较被标为 `non-inferential`，但同一句或同段后续展开同一比较的句子已写出置换检验、符号翻转检验或 `P` 值时，删掉与之矛盾的 `non-inferential` 标签（仅当段内 `P` 值属于另一项不同分析时保留前句标签）；同一句内避免重复出现 `non-inferential` 与 `inferential`，可将冗余的 `without inferential confirmation / ranking` 精简为 `without confirming an advantage / establishing a model ranking`。数字与单位之间、名称与其编号之间加一个空格不改变证据记号，应当补上。不要把 16 改成十六，也不要把两个改成 2。侧车记录补充审计，不代替读者在当前文字附近所需的材料证据引用和科学限定。

预注册或预设、验证性或探索性设计按真实记录描述，不是内部开发史。分别核对是否预设分析、是否实际进行推断检验、是否事后分析、估计与检验结果；“未预设推断阈值”“未进行检验”“不显著”“未建立某关系”不能互换，也不能把所有次要分析自动标成探索性。保留会改变结论的异质性、阴性结果与反例，并让它们继续归属相同对象、终点及分析。

引用靠近实际支持的论断或清楚的连续论断组。合并重复引用需核对相同来源、支配范围和中间是否切换证据；不能只因出现多次便删引或换源。项目口径表、实际图面、作者确认的术语与研究设计决定具体名称及 panel 大小写；技能中的课题例子只是条件示例，不升级为通用禁词或固定表达。
