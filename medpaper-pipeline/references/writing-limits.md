# 篇幅配置与结构编辑

作者和目标期刊的明确要求优先，常规正文不设通用最低词数；不为达到目标补写重复内容。Methods 3,000、Results 4,000、Discussion 1,500词等既有默认上界仅作提示，除非作者/期刊明确规定。摘要默认250词和Introduction既有上限维持原有默认检查；作者/期刊可通过配置明确覆盖。图注默认150词仍为提示。

在含PROJECT.md的项目根可选建立`writing-limits.json`，只登记已由作者或官方期刊要求确认的限制：

```json
{"abstract": {"max": 250}, "results": {"max": 2400}, "discussion": {"max": 1200}}
```

键为abstract/methods/results/introduction/discussion/legends；值为min/max的正整数对象。至少一个字段，min不得大于max；未声明的章节沿用默认，已声明章节仅执行所列限制。min仅用于作者/期刊明确提出的最低值，不自动生成。legends的限制适用于每条图注。引用目标仍由PROJECT写作目标管理，绝不把“Introduction：≥20篇”解析成最低词数。

`manuscript_check.py`沿稿件路径向上定位最近PROJECT.md并读取配置，也可用`--limits-json <文件>`显式指定；配置无效报ERROR。配置中的限制为ERROR，不仅记录WARN。配置优先于旧摘要`--max-words`参数；没有配置时该参数保持原有含义。脚本检查不证明内容充分或叙事清楚。

Finalize结构编辑同时核对项目篇幅配置，记录词数变化及信息覆盖；重复内容删除超过10%不自动失败。旧严格模式的相对词数限制保留以兼容旧调用，不能混用为结构编辑的新契约。

整稿编辑后，ZH及已有EN_ZH按同一科学事实和改后结构同步。英文、中文、合并稿均需前后定位、证据对应和原件归档；仅写“已同步”不构成核对依据。局部口径不清保留原文并继续独立部分；影响主要结论的矛盾阻断受影响交付。
