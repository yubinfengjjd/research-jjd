# 摘要语言与格式

## 1. 四段与篇幅

默认 `## Abstract` 下依次 `### Background`、`### Methods`、`### Results`、`### Conclusions`，每节一个连续段落，无列表。中文对应“背景、方法、结果、结论”。用户给出的 background/method/result/conclusion 统一为这些医学摘要常用标题；指定期刊有单数、不同标题或非结构式要求时按明确要求写，并记录更改。

英文正文默认 ≤250 词；背景通常 2–3 句（约 35–50 词），方法 2–4 句（约 50–75 词，覆盖创新点时可取上限），结果 4–6 句（或按字数自然分句，不得用分号链压缩）（约 90–130 词，覆盖多个分析族时取上限），结论 1–2 句（约 20–35 词）。这些分配用于取舍，不能逐节凑满；总上限优先。方法与结果的详略原则：Methods 尽量完整并突出创新点，Results 详写主终点与核心发现；次要分析仅在影响摘要结论或理解时简述。压缩顺序：泛背景、常规方法细节、次要数字与修饰、次要发现的分句；保留具体空白、创新方法、设计、主终点及其 CI、改变结论的关键例外。摘要优先报告核心证据，不要求全部分析族进入正文；将次要探索性分析留在主文，并在内部覆盖表记录省略理由，不得省略会改变主结论的不利结果。

词数按四段正文空白分词，不计标题、Keywords、Highlights、中文和核查说明；带连字符且不含空白的词算一个。不要剔除统计量来压低词数。另报告含四个小标题的词数；期刊明确计入标题时按含标题计数并服从其限制，未知时不声称遵守某刊系统计数。

`scripts/check_abstract.py` 用 Markdown 标题定位四段，读取 EN 文件而非 EN_ZH 文件；可用 `--limit 200`、`--headings Background Methods Results Conclusion` 指定明确变更。Results 句数为自动估计，须人工确认。非结构式期刊要求时人工划定正文并用同一口径计数，标明该结构检查不适用，不为跑通脚本违背期刊格式。

medpaper-pipeline 的 `manuscript_check.py abstract` 用 `--max-words <限制>` 对齐明确的作者/期刊篇幅；摘要引用确为必要时才用 `--allow-abstract-references`，说明来源核验与格式依据。该脚本不验证出处支持关系，也不能自动识别所有数字单位或 CI 归属。

## 2. 独立阅读与语言

用美式拼写；背景与贡献一般现在时，方法与结果一般过去时。摘要独立于主文，第一次使用必要缩写时定义，即使正文已定义；不必要缩写直接写全称。术语、队列、模型、样本与指标名称沿用已核对手稿/口径表；模型的类别标签等专有写法（如 Normal / Edema / Degeneration）保持原样，不改写为普通疾病名词（normal / edema / degeneration 的小写泛指义）。句式按下方「句长、分号与衔接」执行。

默认没有文献引用、图表号、文件名、代码变量、种子编号、内部规则标签或 citation needed；不使用宣传性形容词和模板式收尾。吸引读者以问题的实际重要性、具体比较、可信发现和贡献的适用范围实现。

中文按中文语序重组，事实、负号、精度、置信水平、统计单位、探索性标签与对冲强度不变。EN_ZH 按四节逐段英文后接中文，不用挤满长表格。

## 3. Keywords 与 Highlights

EN 的四段后另起 `## Keywords` 与 `## Highlights`；ZH 对应 `## 关键词` 与 `## 研究亮点`；EN_ZH 给一一对应的双语项。四份成稿之外不另增附属文件。

- Keywords 默认 3–6 个，分号分隔，围绕疾病/应用、关键方法、评价/设计；不用“创新”“高性能”类词。MeSH 未查证时不声称为 MeSH 标准词。期刊数量/格式要求明确时调整。
- Highlights 默认 3–5 条，每条一个简短完整句，可包含关键数字；一条对应一个有来源的发现/贡献，避免复制整段结论。中英文逐条对应。期刊字符上限未提供时不虚构统一硬限制。
- 不将关键词、亮点算进 250 词；不能通过把必需结果移到 Highlights 来掩盖正文缺失。

## 4. 成稿格式

四个文件名固定：`Abstract_EN.md`、`Abstract_ZH.md`、`Abstract_EN_ZH.md`、`Abstract_核查说明.md`。稿件中不放词数报告、测试标签或核查过程说明；它们放核查说明或过程目录。合成盲测的测试属性由过程报告说明，不把合成结果当作研究成稿或科学证据。

## 句长、分号与衔接

**句长**
- 目标平均 18–28 词/句；单句一般不超过 45 词，**硬上限 60 词**（任何单句不得例外）。
- 避免电报体：不连续出现 <8 词的短句；不得用"增加句子数"回避必要的从句结构，也不得为凑篇幅拉长句子。
- 超过 45 词的句子占全文句数 >10% 时 WARN；任何 >60 词 = ERROR。

**分号**
- 散文分号只允许用于**同一命题的紧密补充**（同一论断的定义、限定或统计注释）。
- **禁止分号链**：同一句内出现 ≥2 个散文分号（无论并列发现还是清单式列举）必须改写——拆为独立句，或改用并列/从属连词（and/but/whereas/because 等），或把清单写成紧凑并列（"we assessed A, B, and C"）。散文分号链 ≥1 处 = ERROR。
- **结构性分号不受限**：缩写表（"BACC, balanced accuracy; CI, confidence interval."）、统计量括号（"(ρ = 0.743; 95% CI, 0.619–0.804)"）、引用列表（"(PMID: 29474911; PMID: 37704728)"）、表格注的缩写行。

**衔接与生动（逻辑性）**
- 主动用连词与从属结构表达因果（because/thus/therefore）、对比（whereas/by contrast）、让步（although/even so）、递进（moreover/in addition）；句子内部用从句承载层次，而非用分号堆叠。
- 段落按科学功能组织；仅在确有逻辑需要时增加过渡或总结，不要求每段有独立收尾句。
- 不连续三句以上以同一个连接词或短语开头；连接词按逻辑需要选用，不为凑数堆砌。
- 仍禁：修辞性、宣传性形容词与无证据的强调（沿用 journal-style 既有清单）；口语化与演讲腔。

摘要适配：以上句长统计只覆盖四段英文正文；Keywords / Highlights 不计入。Results 4–6 句（或按字数自然分句），不得用分号链压缩；正文仍默认 ≤250 词。主题句与段末衔接服从四段功能，不为过渡添加无来源的结果或内容。
