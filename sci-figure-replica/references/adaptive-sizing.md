# 函数化的规模与尺寸适配

这里 n 是依据课题既定分组定义从实际数据识别的任意合法组数（正整数），不设固定数量白名单，不为每个 n 写分支或另建模板。agent 在做课题时自行绑定数据、识别 n，并按图型、标签、附属元素和版面要求编排尺寸、留白、配色和位置；每项宽/高等默认系数只是可覆盖初值。不得擅自改变研究分组含义来适应图形。作者已指定的样式/尺寸限制继续遵守；未指定时按既有单panel、可读字号和间距原则执行。

本规则适用于换数据复用；原图复刻保留源图比例。函数从数据或显式参数获得组数/类别/系列/行列；位置、标签、配色和图例不得固定为原图数量。

按图样选择驱动：分类图W=固定左右留白+n×每组宽度；横向图按条目数增高；矩阵按行列计算；散点不按样本数增大画布。单位、系数、最小间距和字号可配置，长标签可增加留白/单项尺寸。默认保持一个逻辑panel和间距继续加宽/增高，max_width/max_height为空。只有作者明确设上限时超限才协商，不自动压缩、裁切或分面。离散配色不足不得静默循环。

独立函数与draw/render共用核心和尺寸计算；组图draw尊重rect，空间不足交调用层扩大外层布局，不resize外层画布。原图复刻与adaptive复用分开验收；新比例不要求与原图宽高比相同。

分类图由agent按模板选择若干不同组数及适当边界案例，不规定固定测试组数；另查长标签、顺序/列映射、换样本数、颜色不足、显式尺寸/上限及复制到课题不同cwd；横向图/矩阵检查对应维度。比较数值不变、结构数正确、物理间距不缩小、文字与附属元素无裁切。只测原图组数不算完成函数复用。代码/实际运行/科学有效性/作者签核分别记录。
