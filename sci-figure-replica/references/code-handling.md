# 代码三级处理与来源

## 先确认目标对应关系

先核对模型、数据、panel、标签与函数是否对应目标图，再讨论能否运行。提取到 `original_code/` 的代码保持原文/字节，记录帖内顺序、原 fence 语言、SHA-256、缺失数据/函数。原件不能因“修成能跑”被覆盖；改造或重建写进 code/，README 保存差异、命令、授权范围、运行结果和失败原因。原代码未经执行就明确写未运行，不能编造 exit=0。

| 标记 | 使用条件 |
|---|---|
| original_runs | 原帖代码未经改造，实际运行成功且产出目标图 |
| adapted | 为目标图修改原帖代码后实际运行成功，保留修改差异 |
| archived_only | 原代码无法运行、与当前执行无关或未获授权，只归档 |
| reconstructed | 根据目标图另写复刻代码，与数据来源分别标记 |
| example_not_target | 帖内通用示例，与目标图并非同一生成代码 |

`code_provenance` 描述当前复刻代码；`original_code_provenance` 描述帖内代码的对应关系/来源。枚举字段只能放一个值，不能塞入“example_not_target + archived_only”组合字符串。原代码是示例时字段记 example_not_target，另在 README/manifest 写其处置为 archived_only、未运行；新复刻代码记 reconstructed。不抹去通用示例来源，也不将通用示例运行成功等同目标图复现。

## 三级处理

1. **原样运行**：确为目标代码、绘图执行已授权且内容审阅完毕后，使用专用 Python/R 与有界 runner；保存环境、命令、退出码及 stdout/stderr。代码只是输入数据，不因出自帖子就可信。
2. **有限改造**：记录原失败与修改，可在已确认计划内整理依赖/路径/输入输出、参数化和函数化，保留原语言与统计含义。不能补造原始数据、改变统计量、隐式训练或扩展网络/安装操作。
3. **归档与重建**：仍不可运行则 archived_only；若已获按图重建授权，可另写 reconstructed。需要更换语言、未获重建授权或关键数据不可读时停止询问。没有代码时按方法生态推荐 Python/R 并先询问，不因 R 缺包静默换 Python。

## 作者源码函数化与方法关联

原代码可融入复用资源，先分清分析、绘图、文件操作和硬编码参数，给出原函数→修改副本的映射。存档原语言、来源、许可证/未知状态、原字节与 SHA-256，不覆盖原件。方法联想限定为有依据的方法家族推广（如 XGBoost＋SHAP → 满足条件的机器学习模型＋SHAP）：保留原实现，说明适用范围、前提、限制与未实现/未验证分支；不从画法通用性推导宽泛新分析方法。先写文字，有来源代码可按函数契约融入，不自动补算法。家族适用、代码已支持、实际验证三个维度分开，原始版与复用版可在 Wiki 卡片查看，运行在课题环境。

函数契约按实际方法确定，不套一个万能签名：

- **分析函数**：显式输入数据对象、结局/变量/分组列、该算法已有参数与随机性，返回结构化结果表及必要诊断；记录每行含义、输出列/类型、缺失值处理和适用边界。默认不读写文件、绘图、联网、安装包或修改知识库；原算法必要副作用应显式隔离、记录，不能删掉后声称含义不变。
- **绘图函数**：读取结果表，显式列映射、视觉参数和画布/轴传入或返回方式，不隐式训练或重做分析。Python 通常返回 figure/axes，R 保留适合的 plot/grob；多 axes 的边缘分布仍是一个逻辑 panel。导出放显式调用层。
- **独立与组合调用**：分析表可直接传绘图，也可显式保存接口 CSV 后交现有 `render`。保留 `panel.py`、`spec.json` 和 `draw(fig, rect, tables, style)` 适配边界，独立函数、render 与组图共享同一绘图核心，不能复制成两套统计/绘图逻辑。
- **课题复用**：复制所需模块到课题，用课题自己的 Python/R 环境；不依赖原工作目录、知识库路径、硬编码数据路径或全局临时变量。包内相对导入与显式输入相容。不要求制作或全局安装 pip/R 公共包。

普通封装和参数化按已确认计划执行；改变统计逻辑、默认估计量、泄漏边界、缺失值/异常值算法，替换分析算法或补写缺失分析算法时，先说明具体差异并询问作者。按图重建绘图代码的授权不包含补训练、推断或缺失分析算法。方法原实现不适用时写限制，不能为支持“任意模型”强改算法。

验证记录必须包括实际做过的原版与封装版数值等价比较（结果/行顺序/缺失值/随机性；必要容差说明依据）、绘图结构比较，以及复制到课题/不同工作目录、换输入数据后的可移植性检查。未获数据或环境不能做的项目标未测，保留差异与失败证据；一例通过不证明任意数据或模型适用。

## 规模适配与尺寸

函数化须识别可变分组/类别/系列及行列，而非仅封装原图固定规模。按图样确定宽/高驱动，以显式公式参数配置；默认单panel保持间距继续扩展，作者指定上限才询问。复刻保留原比例，复用另测规模适配。完整验收与实现边界见 [尺寸适配](adaptive-sizing.md)。
