# 分阶段文献锚定、数据与防泄漏核查

## 1. 分阶段滚动文献策略（避免第 0 天白做功）

文献检索随课题真实进度分两阶段推进，不为凑篇数而堆砌：

1. **第 0 天轻量摸底（`start` 模式）**：
   - 聚焦 **3–5 篇最核心文献**（强基线代表 + 1–2 篇最接近竞争工作 + 基准数据集/协议出处），快速确认两件事：**没和最新工作撞车**、**第 1 步选的基线足够强且可比**。确认即可开工。
2. **路线跑出苗头后精准补检（`evolve` 模式）**：
   - 当第 1 步验证与错误分析确定要向特定机制或临床条件延伸后，再针对新机制补齐 **3–5 篇精准锚点论文**（优先看全文或关键方法/结果节），逐篇提炼：
     - `HOW`（核心机制）、`WHAT`（实证结果与评测条件）、`LIMIT`（真实局限）、`GAP`（与本课题的具体差异或可借鉴点）。
   - 仅检索真实可访问的数据库（如 PubMed、arXiv、IEEE、期刊官网）；读不到全文时如实标注仅读摘要，不猜测未见细节。需要留存完整查询式与筛选日志时，记入 `00_plan/notes.md`。

## 2. 数据与伦理可行性核查

- **数据盘点**：记录数据集名称/版本、来源入口、模态/变量、样本量及独立单位、标签/终点定义与缺失情况。私有队列基于用户提供的汇总信息或数据字典核实；公共数据检查官方下载/注册条件及许可范围。
- **伦理与权限（记入“执行前待办”，不阻断定稿）**：
  - 私有/医院数据：记录伦理审批或回顾性豁免状态（`已确认` / `待核实` / `执行前待办`）、去标识化方式、数据能否离院/上云及合作协议。
  - 公共数据：记录许可条款（是否允许商用/衍生模型发布）与引用要求。
  - 若伦理或权限尚在办理中，直接在计划书第 7 节列为“执行前待办”，不因此卡死开题或方法设计。

## 3. 独立划分与防泄漏底线

以下四条属于贯穿全课题的科学红线：

1. **按独立单位划分**：同一患者的多次检查/随访、双眼/双侧、同一 3D 体积的相邻切片、同一病理 WSI 的多个补丁、以及数据增强副本，必须严格归属同一划分（`train` / `val` / `test` 跨组零重叠）。
2. **查同源与镜像重叠**：多套公共数据集常存在挑战赛不同年份或镜像再分发重叠，不因平台名称不同就默认独立。
3. **测试集严格隔离**：开发、调参、阈值选择、校准与域适配全部在开发/验证/适配集完成；内部或外部锁定测试集绝不参与选型。
4. **标签与预处理对齐**：多中心或跨队列合并时，提前写清标签映射规则、不可映射类别的处理以及统一预处理口径。
