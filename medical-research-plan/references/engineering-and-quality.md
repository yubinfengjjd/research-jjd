# 工程交接、预算与质量

## 可执行任务契约

G3 科学定义确认后，将方案转成任务 ID、科学目的、依赖、输入和数据模式、实现范围、计划模块/配置、未来命令、输出路径/模式、验收、失败/停止、授权前提和证据状态。命令未实现标 PLANNED；真实脚本存在/读过/运行过分别记录。

按依赖安排：环境与授权核查 → 数据适配/标签/单位 → 重复、划分和泄漏 → 强基线/主分析 → 主方法 → profiling → 比较/消融或敏感性 → 独立验证 → 可信性 → 统计与机器记录归档。按任务适配，不强制临床分析训练 GPU。

主要标签、终点、推断单位、外部数据角色和阈值规则不能由执行 agent 为提升结果私自改动；需回到科学设计。开题完成不自动创建项目骨架、跑分析或训练。

复盘项目的工程节记录实际代码结构（目录、入口、产出），作为代码整理子流程的输入。

医学影像 AI 如需后续自主诊断、换方法并重训，先按 [自适应交接](adaptive-handoff.md) 提议判定式、贡献要求、预算及权限，由作者首次确认并授权。默认开题不启用执行授权；不能把“计划可交接”当作已获训练、profiling 或资源下载许可。

## 资源估算

记录模型/分析、数据规模及单位、输入尺寸/变量数、硬件/显存/RAM、精度、真实 batch/梯度累积、epoch 上限/早停、运行次数/重复/搜索、I/O、估算依据及上下限。

总账本覆盖全部基线、主方法、消融/敏感性、重复、搜索、评价和重跑余量，不能只算一次主模型训练。最大预算按运行上限，早停只影响可能实际用量。推理区分 batch=1、吞吐 batch、批延迟、摊销每例与端到端，注明预处理/I/O。

区分估算、参考实测和本机实测；不能把其他硬件单点时长当本机 benchmark。无合理依据给 UNKNOWN 和校准任务。profiling 属后续执行，不自动运行。缩模型/分辨率/重复/模块时说明对科学主张的影响，违反硬条件回退节点。

## 一致性表

字段：检查 ID、检查项、章节/声明 ID、是否一致、证据状态、说明、冲突类型、优先硬约束、降级/替代、修订动作、失效节点、复核结果。

检查任务—数据输入/标签；推理模态/变量—可得信息；临床路径位置—对照/操作点/指标；参考标准—标签来源；锚点差异—方法/设计；主张—验证—指标；独立单位—划分—统计；样本/事件数—区间精度与亚组；开发/适配/校准—外部测试；伦理/许可—数据用途与算力位置；预算与时间—所有运行配置与截止节点；科学定义—工程接口。

每项主要贡献在 claim–evidence 矩阵中至少有一行决定性证据：

| 主张 | 贡献 | 必需对比 | 消融/诊断 | 压力/边界检验 | 指标或观察 | 反证结果 | 状态 |
|---|---|---|---|---|---|---|---|

实验选择有意延后时写 TBD，不编造预期数值。

每项主要贡献至少有可区分假设和替代解释的验证。关键不一致不能靠总体得分通过，任何冲突裁决回指具体声明，修订后再次核对。未解决关键未知/硬失败时只交暂定，不能为了表格全“一致”而编造解决。

## 独立审查

先检查结构与登记，再用当前真实可用 subagent 独立审查。继承实际模型设置，不硬编码模型/配置，不为此自动安装 agent/MCP 或扩大权限。

给最小必要原始材料：任务/约束、数据证据及角色、关键来源与阅读范围、假设/方法、实验/统计、预算、任务及未知。不要预先提供作者希望的结论；审查者核对声明与证据，不盲信 VERIFIED 标记。

审查者只输出问题 ID、严重程度、原声明/依据、影响、修订建议、需回退节点和未核查事项，不修改数据/代码，不批准用户决策、不训练或问用户。检查最近竞争、简单基线、替代解释、泄漏、单位、预算和不可获得依赖。

主 agent 对每项采纳/拒绝/暂缓给理由与证据。改变主要科学定义回退受影响节点；普通细节在边界内改。建议最多两轮定向复核，无进展或重大缺口保留暂定与下一步。

工具不可用记录 SELF_REVIEW_FALLBACK 和原因，照清单自审但不叫独立审查。科学核验与结构通过不同。

## 结构检查

轻量模式按下方一致性表和主文义务人工检查即可，在 review.md 写明“未启用机器登记”。完整登记时，输入使用 assets/records-template.json 的实际字段，有 Python 执行 `scripts/validate_plan.py <项目目录> --output <新报告路径>`，输出已存在只有明确 `--force` 才覆盖。检查器不改输入、不联网、不下载、不训练。

0 表示显式结构/规则无错误，1 表示直接登记矛盾，2 表示输入/运行/输出操作错误。正确 PROVISIONAL + UNKNOWN 可以结构通过但不表示已可正式交接；READY 与关键未知/未确认矛盾应拒绝。未检查语义报告 needs_review。

主文按实际用户模板独立可读，必含范围、研究问题、数据、方法、实验/分析、指标统计、可信性、检索、裁决、工程交接与限制义务。默认不附 Fig/Table 或成图样式，必要核查表/流程/伪代码可用。研究数字、预期收益和已执行结果不虚构。
