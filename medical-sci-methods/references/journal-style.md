# 期刊语言与格式规范

作者于 2026-10-12 确认。适用于医学 SCI Methods 的英文正文及中文对照。目标期刊或用户另有要求时，按其要求执行。

## 1. 拼写、缩写与命名

- 默认使用美式拼写，并保持全文统一：normalized、randomized、modeling、hemorrhage、edema、center、tumor。专有名词和引用题名保留原拼写。
- 缩写在 Methods 中首次出现时写出全称，例如 area under the receiver operating characteristic curve (AUROC)。即使摘要或引言已定义也照此处理，因为读者常单独阅读 Methods。只出现一次的术语不缩写。
- 研究提出的模型、数据集和外部工具，须在首次使用前正式引入。不在引入模型之前写“the model's input size”。
- 统一术语表：同一对象全文只用一个名称，中文对照也固定一个译名。不交替使用 cohort、dataset、source。
- 不用斜杠并列概念（target/stratum、fitting/evaluation）；写成 “each target cohort or stratum”。专有名称中的斜杠（DR/DME 等）按惯例保留，首次出现时展开。

## 2. 时态、语态与句式

- 已执行的步骤用一般过去时（were trained、was estimated）。定义、公式和软件功能可用一般现在时。
- 数值写法：小于 0.001 的参数（如学习率、容差）用科学计数法，写作 \(3\times10^{-4}\)、\(10^{-5}\)，不写 0.0003、0.00001；P 值和比例按常规小数书写。全文同类参数写法一致。
- 根据信息重点选择被动或主动语态，不要求全文统一为被动语态。可用 “we” 说明研究者的决定，但不要每句都以 we 开头。
- 不使用工程或项目管理词汇代替方法术语，例如 audit、repair、firewall、ledger、closure、transport、wave、run。分别改写为 verified、reconciled、held out、cross-cohort recalibration 等，具体词按实际含义选择。
- 中文对照写成规范的中文学术表达，不按英文语序逐词直译。中文同样避免“审计”“修复”“闭合”等工程词，但事实和限定范围须与英文一致。
- 中文对照的格式：引用标识用全角括号，如“Smith（PMID: 12345678）”；英文术语首次出现时给出通行中文译名，如 B-scan 写作“B 扫描”，此后统一用中文。数据集、模型、软件等专有名称保留英文原名。

## 3. 引用

- 正文引用统一使用纯文本标注，按以下优先级取一种：PubMed 收录的来源用 `(PMID: XXXXXXXX)`；确无 PMID 时用 `(DOI: 10.xxxx/xxxx)`；正式出版版本没有 DOI 时用作者、年份及正式出版页 URL；只有预印本、没有正式出版版本时用 `(arXiv: XXXX.XXXXX)`。会议论文（如 ICCV、CVPR、MICCAI）通常有 DOI，应先确认后再考虑 URL。投稿稿正文不使用 Markdown 超链接。
- 标识必须属于正文所引用的那个版本（期刊论文、会议论文、书章节或预印本）。同一作品的其他版本有 DOI，不能拿来代替。
- 引用对象优先选方法的原始或标准出处，即首发的期刊或会议论文，不为了凑出 PMID 或 DOI 而改引书章节、扩展版或转载版本。
- 所引的正式出版版本（期刊或会议论文）没有 PMID 和 DOI 时，用作者、年份及正式出版页 URL，例如 “(Koh et al., 2020; URL: https://proceedings.mlr.press/v119/koh20a.html)”，不改用该作品的 arXiv 预印本号（作者 2026-10-12 确认）。arXiv 号只用于作品本身只以预印本形式存在、没有正式出版版本的情形。
- 若因上述规则改动了旧稿的引用版本，正文的作者、年份和来源随之一致，并在核查说明中注明。
- 需要引用：数据集和数据库、预训练模型、研究采用的具名算法和损失函数、非标准统计程序、研究所依赖的重要软件库。
- 标准方法免引：教科书级统计和描述方法不需要追溯原始文献。包括 t 检验、χ² 检验、Wilcoxon／Mann–Whitney 检验、Pearson／Spearman 相关、Kolmogorov–Smirnov 检验、bootstrap 置信区间、主成分分析、逻辑回归、ROC／precision–recall 分析、Dice 系数、交叉熵损失。
- 以下情形仍应引用：方法有具体变体或命名程序，例如 Benjamini–Hochberg、DeLong 检验、决策曲线分析、保形预测、Grad-CAM；或者目标期刊要求引用。
- 判断不清时，按“该方法是否属于医学统计教材的常规内容”判断。免引决定无需写入核查说明。

## 4. 软件、伦理与报告规范

- 软件写法：名称、版本号及其在本研究中的用途，用一句话说明，例如 “Models were implemented in PyTorch (version x.y)”。版本号只从材料中的环境文件、lock 文件或运行回执获取；找不到时不编造，列入核查说明。
- 伦理与数据使用：材料中有伦理批准、豁免或公开数据许可的说明时，写入研究设计相应位置。材料中没有时不编造，列入核查说明请作者补充。
- 报告规范：预测或诊断模型研究对照 TRIPOD+AI，医学影像 AI 研究对照 CLAIM。只在核查说明中列出这些规范要求、但材料中缺失的关键要素（如样本量依据、缺失数据处理、硬件或代码可用性）。不强制按条目改写正文结构。

## 5. 篇幅与主文范围

- 完整 Methods 主文 2,500–3,000 英文词仅作规划参考，无通用最低词数；作者/期刊明确限制优先。叙事确有需要时可以超过 3,000 词，不因字数删去必要的方法事实。
- 尽量不把内容分流到补充材料。默认不撰写 Supplementary Methods，除非用户明确要求。
- 控制篇幅优先靠删除实现层细节、重复限定和冗余参数，不靠压缩方法逻辑。同一句不堆叠三个以上独立参数；参数较多时拆成两句，或只保留影响方法理解的参数。
- 超过约 8 项的同类枚举（如概念词表、病种清单），正文已有对应 Table 时改为引用该表，例如 “The 16 concepts are listed in Table 2”；没有对应表时保留枚举，不为此新建补充表。
- 交付时报告英文词数，统一口径：只统计正文段落，不计各级标题、括号内引用标识（PMID/DOI/arXiv/URL 及作者年份）和行内公式；用本地脚本按空白分词计数，报告时注明“正文段落、不含标题与引用标识”。超过 3,000 词时，先逐节检查是否混入了实现细节、结果数字或重复限定（见 `writing-rules.md` 第 5 节），删除后仍超出且属于叙事需要的，可以保留。

## 句长、分号与衔接

**句长**
- 目标平均 18–28 词/句；单句一般不超过 45 词，**硬上限 60 词**（任何单句不得例外）。
- 避免电报体：不连续出现 <8 词的短句；不得用"增加句子数"回避必要的从句结构，也不得为凑篇幅拉长句子。
- 超过 45 词的句子占全文句数 >10% 时 WARN；任何 >60 词 = ERROR。

**分号**
- 散文分号只允许用于**同一命题的紧密补充**（同一论断的定义、限定或统计注释）。
- **禁止分号链**：同一句内出现 ≥2 个散文分号（无论并列发现还是清单式列举）必须改写——拆为独立句，或改用并列/从属连词（and/but/whereas/because 等），或把清单写成紧凑并列（"we assessed A, B, and C"）。散文分号链 ≥1 处 = ERROR。
- **结构性分号不受限**：缩写表（"BACC, balanced accuracy; CI, confidence interval."）、统计量括号（"(ρ = 0.743; 95% CI, 0.619–0.804)"）、引用列表（"(PMID: 29474911; PMID: 37704728)"）、表格注的缩写行。

**衔接与生动（逻辑性）**
- 主动用连词与从属结构表达因果（because/thus/therefore）、对比（whereas/by contrast）、让步（although/even so）、递进（moreover/in addition）；句子内部用从句承载层次，而非用分号堆叠。
- 段落按科学功能组织；仅在确有逻辑需要时增加过渡或总结，不要求每段有独立收尾句。
- 不连续三句以上以同一个连接词或短语开头；连接词按逻辑需要选用，不为凑数堆砌。
- 仍禁：修辞性、宣传性形容词与无证据的强调（沿用 journal-style 既有清单）；口语化与演讲腔。

Methods 适配：主题句交代方法目的，衔接限于已执行步骤的逻辑，不增添结果或讨论。
