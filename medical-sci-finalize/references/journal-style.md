# Word 版式与引用候选清单（批次 #10，v7）

以作者指定的本地参考稿为版式基准，不改任何稿件文字。本批替代批次 #9 的段后插入、拆续表、Heading 样式及 References 规则。

## 页面、字体与标题

- 两份 Word 均为单节 A4 纵向 21 × 29.7 cm，四边页边距 3.2 cm，可用正文宽 14.6 cm；不扩纸、不横向。
- 全部英文 Arial；正文 12 pt、单倍行距，段前后 0 pt；无行号、页眉页脚内容和 PAGE 域，无装饰线、手动分页。
- 首页四行占位：[Manuscript title] 16 pt 粗、[Authors] 10 pt 粗、[Affiliations] 和 [Corresponding author] 常规 12 pt。随后一个空段落，再接 Abstract。
- **所有标题都是 Normal 段落 + 直接 run 字号/加粗**。document.xml 不得出现 Heading*、Title* 的 pStyle 或 outlineLvl；不能用样式继承引入大纲级别。未使用的内置样式定义可以保留。
- Abstract、Introduction、Methods、Results、Discussion、Keywords、Highlights 为 15 pt 粗；二级/三级及以下标题为 12 pt 粗。补充材料总标题 16 pt 粗。摘要为 run-in 标签格式（Background:/Methods:/Results:/Conclusions:，标签加粗、与正文同段同字号），见下方“图表位置与空行”节。

## 图表位置与空行

- 只扫描 Abstract → Introduction → Methods → Results → Discussion 的源正文段落，识别每个主图/主表的首次引用。兼容 (Fig. 1…)、(Figure 1…)、(Table 1) 和叙述式引用；排除 S 编号及 Supplementary 前缀，不从插入的图表注触发资产。无正文引用的主资产报 ERROR。
- 首次引用之前最近的源标题确定所属（子）节，级别 L。资产放在该节全部正文（包括其下级小节）之后、下一个级别 ≤L 的标题之前。例：2.3 引 Fig1 和 Table2，放在 2.3 末、2.4 前；2.3.1 引用则放在 2.3.1 末、2.3.2 前。
- 同一所属节的资产按正文首次引用位置混排 Fig/Table；每资产仅一次。标题语义层级独立保留在组装事件中，不依赖 Word Heading 样式。
- 图块为图段 + 完整图注；表块为表题段 + 全部表格区块 + 表注段；区块之间恰好一个普通空段落，表题和表注各出现一次。标题句粗体，其余注释常规。标签和标题文字不改，不加 (continued)。
- 下列边界各一个普通空段落（Arial 12 pt）：标题块→Abstract、摘要正文→Keywords、Keywords→Highlights、Highlights→Introduction、每个一级节之间、每个图块/表块前后。相邻两个资产共享一个空段，不堆叠双空行。含 drawing 的图段不算空段。
- **同级（子）节之间也空一行**：任何编号（子）标题（2.1、2.1.1…）之前加一个空段，**除非**其紧邻的前一段就是它的直接父标题（如 Methods→2.1、2.1→2.1.1 之间不空行；2.1.1 正文→2.1.2、2.1.2 正文→2.2 之间空一行）。
- **摘要为 run-in 标签格式**：`Abstract` 之下是连续四段，每段以加粗标签 `Background:` / `Methods:` / `Results:` / `Conclusions:` 开头、冒号后同段接正文（标签与正文同为 Arial 12 pt，标签加粗）；四段之间**不空行**；Abstract 标题与第一段之间不空行；第四段与 Keywords 之间空一行。中文对照不受影响。
- 补充材料按附图 S1–S12 数值顺序，然后附表 S1–S10 数值顺序；不做正文节末逻辑，不强制每资产一页。编号范围随资产发现，集合/连续性/图注对应须精确一致。

## 图片、图注与表注

- 图宽固定 14.6 cm，保持原始纵横比。自然流式，不设置图→图注 keepNext、同页绑定或强制分页；不因图注长度缩图。组图嵌入其 **TIFF**（`figN.tif`/`sNN.tif`，600 dpi、LZW、RGB），投影/原图件直接嵌入、不转换；tif 缺失时回退 `figN.png` 并出 WARN（请上游按 TIFF 导出重生成）。
- 图注完整保留；源标签加标题句粗体，标题句取标签后的第一个句末标点。panel (a) 及描述、后续正文和尾注常规，不整段粗体。表题使用相同标题边界，余下表注移至表后并保持原文。
- 高瘦图可能超过页高；实际分页/可读性须另用 Word 或渲染器复核，不能以 XML 检查代替视觉验收，不得删改图注、重绘或补数。

## 原生 Word 单表

- 每源表中的每个 Markdown 表格区块生成一个可编辑 w:tbl（单区块输出保持不变），14.6 cm 满宽，网格线、单倍行距、固定列宽，tblW/tblGrid/tcW 一致。首行 w:tblHeader 重复；不设 cantSplit 或 keepNext/keepTogether，允许行自然跨页。
- 表内字号 **8→7.5→7→6.5 pt**。按包括表头的每列最长单词估算：Arial 实测 ×1.08 +12.8 pt 单元格余量，向上取整至 twip；词宽能够容纳时，剩余宽按完整内容宽度权重分配，整 twip 舍入保持总宽。
- 6.5 pt 仍超宽时保持硬地板，保留能容纳的短字段列，剩余列按词宽比例分配，并显式允许词内断行。不得拆续表、重复标识列、删列、改字、扩纸或横向。出 WARN，指出表号、仍需断词的列与样例。
- manifest 和独立检查报告逐表记录最终字号、断词列、表头及样例；过程目录 `表格断行清单.md` 完整列出这些信息，便于作者后续精简标签。测量结果是估算，不宣称 Word 已实际断词或可读性通过。
- 显示层解码 Markdown 反斜杠转义，按反斜杠奇偶识别分隔竖线，保留空值。数学段不经过转义解码，使用可编辑 OMML，未知 TeX 命令报错。

## 引用候选与检查边界

主稿不生成 References 标题或文献表。正文 PMID/DOI/URL/arXiv 标识原样保留。过程目录 `参考文献候选清单.md` 按源正文首次出现去重，再收录仅图表注出现的标识，列已有可核字段、核查表来源和缺口。本地字段不全、核查表无记录、明示未核验均写入该清单，不进入成品 WARN；不联网补证，不伪造元数据。本例本轮有 37 个标识；数量因稿而异，不是固定规则。

`check_finalize.py` 检查页面、字体、标题直接格式、无 Heading/Title/大纲级别、空段及节末插入顺序、无 References；逐表核对源区块数、单次表题表注、块间空段，并逐块核对字号、列宽、重复表头、允许跨页、完整源单元格（含空值和公式），逐图核对宽度/比例/图注粗体范围。不再输出 reference_count 或执行正文标识=文献表集合断言。源正文和图表注逐段一致检查继续保护所有引用标识。

图注词数沿用 pipeline：去 Markdown 标题、括号内文献/图表引用和独立 panel 标签后按空白分词；编号和标题计词。兼容 (a)、(a-c)、(a–c)、中文括号和标签后标点；x(a) 与科学括号保留。Figure 1 为 161 词时保留原文、WARN 待作者裁决。

本规则不是目标期刊已验证模板。检查报告的 submission_ready 恒为 false；无 ERROR 不证明实际分页、可读性、科学有效性、引用核验或作者验收。真实作者信息、文献表插入及科学未决事项仍待作者处理。

## 句长、分号与衔接

**句长**
- 目标平均 18–28 词/句；单句一般不超过 45 词，**硬上限 60 词**（任何单句不得例外）。
- 避免电报体：不连续出现 <8 词的短句；不得用"增加句子数"回避必要的从句结构，也不得为凑篇幅拉长句子。
- 超过 45 词的句子占全文句数 >10% 时 WARN；任何 >60 词 = ERROR。

**分号**
- 散文分号只允许用于**同一命题的紧密补充**（同一论断的定义、限定或统计注释）。
- **禁止分号链**：同一句内出现 ≥2 个散文分号（无论并列发现还是清单式列举）必须改写——拆为独立句，或改用并列/从属连词（and/but/whereas/because 等），或把清单写成紧凑并列（"we assessed A, B, and C"）。散文分号链 ≥1 处 = ERROR。
- **结构性分号不受限**：缩写表（"BACC, balanced accuracy; CI, confidence interval."）、统计量括号（"(ρ = 0.743; 95% CI, 0.619–0.804)"）、引用列表（"(PMID: 29474911; PMID: 37704728)"）、表格注的缩写行。

**衔接与生动（逻辑性）**
- 主动用连词与从属结构表达因果（because/thus/therefore）、对比（whereas/by contrast）、让步（although/even so）、递进（moreover/in addition）；句子内部用从句承载层次，而非用分号堆叠。
- 段落按科学功能组织；仅在确有逻辑需要时增加过渡或总结，不要求每段有独立收尾句。
- 不连续三句以上以同一个连接词或短语开头；连接词按逻辑需要选用，不为凑数堆砌。
- 仍禁：修辞性、宣传性形容词与无证据的强调（沿用 journal-style 既有清单）；口语化与演讲腔。

润色适配：以上规则用于候选稿诊断与人工改写，不授权组装阶段修改源正文或删除限定；WARN 逐条登记。Keywords / Highlights、标题与表格单元格不纳入散文句长统计，主/附图注和表注纳入。
