Honor the existing Claude connection configuration by loading only a documented authentication/model-connection environment allowlist from its existing user settings into child process memory, overriding stale inherited equivalents. Never relabel a Claude review as Codex. Old Codex invocation records without backend remain supported without weakening existing gates.
- A restricted Claude reviewer cannot inspect historical Git objects through shell tools. For pending repair/method classification, the controller embeds actual bound prior/current commits, the archived prior proposal and the complete approved-source diff in the invocation input. Reject stale/dirty/missing/out-of-scope evidence before calling the CLI; preserve independent classification, budgets and tool boundaries.
