# Claude Code 后端工程验收（2026-10-20）

范围是 Windows 上的原生 Claude Code CLI 后端及共享实验控制流程，不是医学研究有效性验收。实际使用 Claude Code 2.1.302，沿用作者配置的服务模型 `deepseek-flash[1m]`；没有强制模型或改用直接模型 API。这证明的是 Claude Code CLI 宿主适配，不是 Anthropic 模型验收。

## 实际执行

- 真实 CLI 连通、结构化输出及独立 UUID 会话通过；实际只读工具清单为 Read/StructuredOutput，允许的源码可读，范围外读取被拒绝。限制来自 CLI 工具和目录权限，不是操作系统沙箱。
- 在 RTX 3050 Laptop GPU、PyTorch 2.9.0+cu126 上运行生成数据的 2D 分割任务。原始主方法与基线相同，正式验证无贡献，保留负结果后自动提出一次仅改初始化的源码修订。
- 控制器实际提交修订、更新当前计划并归档旧文档，经另一个新会话审查后筛选和约定的正式训练，正式 seeds 为 11、22、33。有效条件未变的基线与消融复用原始结果，来源版本保留。
- 正式比较与贡献门通过后冻结，三个预定条目各进行一次最终测试；测试后停止搜索。成功案例共 15 次训练、93.156 秒训练账本、一次方法修订，无故障重试。
- 首个工程案例因审查元数据路径带注释而停止，没有裁剪输出或伪造通过。修复结构化路径约束并复审后另建验收案例，保留原绝对截止时间，训练额度从 300 秒降到剩余 249 秒，故障重试额度降为零。首轮 50.345 秒仍保留，合计训练耗时 143.501 秒，不重置预算或科学边界。
