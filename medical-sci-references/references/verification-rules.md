# I1–I9（含 I7a）与交付核查

本页检查原生域中间阶段。它保留原标识结果用于逐字符核对，不能验证最终可见编号或书目完整性；完成稿必须再通过[可见交付检查](rendered-delivery.md)。旧检查与新缓存检查分别留证，不削弱I1–I9来容纳编号替换。

输入：原标识/字段源主稿、新候选、引用清单、Zotero条目快照、基准样例；重跑时另给上一轮清单，人工保留核查传缺口文件。输出核对报告 JSON 和 Markdown，含逐项证据与每处标识/种类/源和新位置/key/DOI/状态。

| 项 | 检查证据 |
|---|---|
| I1 | 从源重新抽取，与清单每处及首现去重集合精确对应；状态∈既有/新增/人工保留/作者指定；源SHA256一致 |
| I2 | 非人工处数=引文字段数；每域非空且 citationID 唯一 |
| I3 | 字段 begin 的段落与可见字符偏移、完整占位文本、前后段落文本均对应原处；图注表注包含在内 |
| I4 | citationItems 整体与库快照完全相同；DOI/PMID/arXiv桥接与标识对应，多篇顺序一致；同URI整数id及payload稳定；作者指定还须字段key=resolution.item_key，并保留映射文件路径和note |
| I5 | 还原引文占位并剥离文末新References块后，逐段逐字符的文字及 rPr 直接格式完全相同 |
| I6 | 文献表字段恰一个、位置为文末References标题之后；偏好存在、样式固定、fieldType=Field；custom part和根关系注册 |
| I7 | 非修改包part逐字节相等，图片哈希不变；还原后的非文字XML骨架相等，覆盖表格网格、段落属性、图片顺序、四个占位行与分节页面设置；无关custom属性/注册不变 |
| I7a | 每个 lastRenderedPageBreak 的段落、可见字符偏移、标记XML/属性、run属性及rPr与源稿逐处一致；移动、丢失、重复或改属性/格式均为ERROR |
| I8 | 人工保留每处有原因、缺口清单可查，正文原文不变；正常人工保留记WARN，缺登记则ERROR |
| I9 | 字段源从占位还原的标识/位置集合与上一轮清单一致，字段中条目key顺序也一致；清单漂移则拒绝 |

I1–I7、I7a、I9 失败阻断 apply。人工原因缺失同样阻断。metadata 缺失、题名兜底、原生PMID迁移、三方核对差异逐条进入WARN；作者指定单列WARN级“作者映射、需作者确认”，不以原始URL等于条目URL替代映射key核对。WARN 不等于已裁决；本地书目冲突必须先裁决。

apply 重新跑检查，使用源稿版本号加1；将源稿移至 `_archive/<日期>[_序号]/05_final/`，候选副本原子发布并检查SHA256，随后更新PROJECT第12行“待确认”和作者决定References节。源/产物/跟踪任一步失败均恢复源与跟踪，将未完成新文件留过程目录供审计，不删除文件。独立使用只在指定输出目录归档和发布，不生成PROJECT。

原始样例和源稿只读。候选不可覆盖源稿或已存在候选；换新过程目录重试。仅新增支持一个 lastRenderedPageBreak 位于纯文字前或后的混排run（rPr可选）：拆分保留分页标记在原字符锚点，节点属性、run属性与直接格式均保留；标记与文字整体恰好构成引用run时也能保留。I7仅对这两种已证明形状剥离文字比较骨架，分页锚点另由I7a严格比较，不能用骨架相等替代位置不变。内部夹杂分页标记、softHyphen/noBreakHyphen等未证明混排、其他容器、跨容器复杂域、特殊Zotero fldSimple或非预期文献表布局仍明确拒绝，不重写整段绕过检查。

## 重跑

优先用字段版。未刷新字段保留原标识，能无损复原并重新注入；从restored_fields记录原字段JSON。给 `--previous-manifest` 校验原处与原条目key顺序。刷新后显示为数字、占位文字消失时必须有旧清单，且恢复后的格式只能以当前结果run为依据；如曾有跨run混合直接格式而无法恢复，使用归档的标识版重做，不能声称还原了失去的格式。重跑前查重，不能多写条目或增加第二个References块。

## 人类验收

机械检查不证明 Word 打开、Zotero Refresh 成功、文献支持正文论断或目标期刊格式合规。请作者在 Word 打开字段稿，点 Zotero 的 Refresh（引文变为编号），检查至少3处（含重复、多篇）与完整文献表及图表位置；**若 Refresh 后文末文献表仍为空，点一次 Add/Edit Bibliography 即生成**（作者实测 2026-10-16）。验收后由作者确认阶段12。阶段11重建后第12阶段需返工，不用 finalize 的“无References/纯文本标识集合”断言验收字段稿。
